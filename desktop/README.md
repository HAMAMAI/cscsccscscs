# Такт для Windows

Отдельный desktop-клиент на Electron. Он использует тот же Supabase-профиль,
чаты и LiveKit-комнаты, что и Android-приложение.

## Что уже подключено

- вход и регистрация через Supabase Auth;
- загрузка списка чатов и сообщений, поиск людей, личный диалог;
- текст, файлы, ответ и реакция;
- архив и отключение уведомлений на восемь часов;
- голосовой канал: микрофон, камера, демонстрация экрана, громкость,
  отключение звука, выход и завершение звонка для всех;
- отдельная LiveKit-личность на каждой установке. Один аккаунт может
  находиться в комнате одновременно с телефона и ПК.

## Локальная сборка

\`\`\`powershell
cd desktop
npm install
npm run package:win
\`\`\`

Готовый установщик будет в \`desktop/release/\`.

Переменные окружения необязательны для текущего проекта и нужны только при
смене окружения:

\`\`\`text
VITE_TAKT_SUPABASE_URL=https://your-project.supabase.co
VITE_TAKT_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
VITE_TAKT_CALL_TOKEN_URL=https://call.example.com
\`\`\`

В desktop-клиент нельзя добавлять service-role ключ, приватный ключ LiveKit,
пароль VPS или SSH-ключ. Они остаются только в секретах GitHub Actions и на
сервере звонков.
